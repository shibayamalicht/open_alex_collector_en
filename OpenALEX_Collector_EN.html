Q Paper Search
Command-line search expression: Command-line search expressions let you enter search conditions as numbered command rows such as #01 / #02 and then combine them at the end as T=(#01 AND #02) OR #03.
Each command row must explicitly specify one of TI= / AB= / TA= / TX= / FT=.
You can leave keywords blank and search only with the institution or author filters.
In command-line mode, each row's field specification and the T expression control the search scope and logic. In standard mode, search terms are passed directly to OpenAlex.

Detailed rules for command-line search expressions

Command rows

#01 and #02.
Enter one search condition per row.
Each row must explicitly specify one of TI=, AB=, TA=, TX=, or FT=.

Combined logical expression T

T=(#01 AND #02) OR #03
#1 and #01 refer to the same row.
When using multiple rows, enter the T expression.

Fields

TI=(...) Title
AB=(...) Abstract
TA=(...) Title + abstract
TX=(...) OpenAlex general search target (candidate retrieval)
FT=(...) OpenAlex fulltext index (candidate retrieval)

Search scope

In command-line mode, the Advanced Filter "Search scope" is disabled.
Specify the scope in each row using TI= / AB= / TA=.
Rows without a field specification are syntax errors.

Boolean

A AND B contains both
A OR B contains either
NOT A exclude

Proximity and wildcards

A near5 B within 5 words in any order
A adj3 B A appears before B within 3 words
cathod* / wom?n
Example:
#01  TI=(solid adj3 electrolyte)
#02  AB=((degradation AND capacity) near8 (mechanism OR fade*))
#03  TA=(review)
T=(#01 AND #02) AND NOT #03
Note: Strict internal proximity evaluation applies to TI, AB, and TA. TX and FT can be used for OpenAlex-index-based candidate retrieval, but when full text is not available inside Collector, strict near/adj verification and snippets are not generated. For TA, near/adj is evaluated within title or abstract separately, not across the title-abstract boundary.

★ Citation Rankings
Citation-based analysis: Ranks authors, institutions, and journals by citations (quality/impact), not only paper count (quantity). The h-index is a standard quantity × quality indicator. Recalculate each tab with the "Render" button.
X-axis = paper count (quantity) / Y-axis = average citations (quality) / bubble = total citations. Upper-right indicates high output and high citation impact. Hover to show author or institution names.
h-index = the maximum h such that at least h papers have each been cited at least h times. Calculated only from papers and citations in this collection; it differs from an OpenAlex-wide h-index.

Collaboration aggregation: When a paper lists multiple institutions, each institution pair is counted as a collaboration pair (for example, A, B, and C generate A × B, A × C, and B × C). Recalculate each tab with the "Render" button.
Lists collaborators of the selected institution in descending order by coauthored paper count. Center-institution candidates are sorted by number of unique collaborators.
Number of unique collaboration partners for each institution. Higher values indicate hub-like institutions collaborating with many diverse partners.

Reference analysis: Aggregates each paper's referenced_works (IDs of cited works) to visualize foundational references, co-citation, bibliographic coupling, and internal citation networks. OpenAlex citation coverage varies by publisher and field, so some papers may have empty reference information.
Note: A. References Top-N and B. Co-citation pairs Top-N make additional OpenAlex API requests during rendering to fetch Top-N metadata.
Top-N external papers most frequently cited by papers in this collection. Useful for identifying foundational or classic references. Title, year, and venue metadata are additionally fetched from OpenAlex (a few seconds).
Counts how many times "reference A and reference B are cited together by the same paper" for each pair. Useful for identifying pairs belonging to the same school or stream. API access occurs to fetch Top-N metadata.
Number of references commonly cited by paper A and paper B within the collection. Higher values suggest closer scholarly proximity and possibly the same research community or theme.
Visualizes citation relationships among papers in the collection as a network (vis-network force layout). Arrow source = citing paper; arrow target = cited paper. Node size = citations within the collection. Color = publication year (older = orange, newer = blue). Hover over nodes for paper information; click for a detail popup. Drag and zoom with the mouse.
